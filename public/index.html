Statistical Methodology & Mathematical Architecture

End-to-end delivery-level pressure evaluation, Empirical Bayes shrinkage, cross-role standardization, and cluster bootstrap uncertainty.

1. Context-Aware Continuous Pressure ($P \in [0, 100]$)

Computed pre-delivery from cumulative team runs, remaining balls, wickets in hand, required run rate, and match closeness:

$$P_{\text{chase}} = 100 \cdot \big(0.38 S_{\text{rate}} + 0.32 S_{\text{wicket}} + 0.20 S_{\text{urgency}} + 0.10 S_{\text{rate}} S_{\text{urgency}}\big)\,(0.35 + 0.65 C_{\text{match}})$$ $$S_{\text{rate}} = \frac{1}{1 + e^{-0.45(\text{RRR} - 9.5)}}, \quad C_{\text{match}} = 4 P_{\text{win}}(1 - P_{\text{win}})$$

High-pressure cutoffs: $P_{\text{bat}} \ge 50.0$ (batting) and $P_{\text{bowl}} \ge 55.0$ (bowling), contrasted against individual normal baselines ($P < 50$ / $P < 55$).

2. 5-Pillar Reliability Scores (BRS & PRS)

Combines shrunk execution, personal resilience retention, consistency, leverage, and sample confidence:

$$\text{BRS / PRS} = 0.30\,\text{Exec} + 0.25\,\text{Resilience} + 0.20\,\text{Consistency} + 0.15\,\text{Leverage} + 0.10\,\text{Confidence}$$ $$\hat{\theta}_i = \frac{n_i \bar{x}_i + k \mu_{\text{cohort}}}{n_i + k}, \quad (k_{\text{bat}}=60, \; k_{\text{bowl}}=80, \; k_{\text{death}}=40)$$

Shrinkage is also applied to $\Delta\text{SR}$ and $\Delta\text{Economy}$ so small-sample players cannot achieve inflated Pillar 2 spikes.

3. Precision-Weighted Cross-Role Standardization

Places batters, bowlers, and dual all-rounders on a fair common scale while penalizing low-volume uncertainty:

$$Z_{\text{adj}} = \left(\frac{\text{Score} - \mu_{\text{role}}}{\sigma_{\text{role}}}\right) \cdot \frac{n_{\text{pres}}}{n_{\text{pres}} + \tau_{\text{role}}}, \quad \tau_{\text{role}} = 0.5 \cdot \text{median}(n_{\text{pres, role}})$$ $$Z_{\text{overall}} = Z_{\text{primary}} + 0.35 \cdot \max(0,\, Z_{\text{secondary}})$$

Calibration using $\tau_{\text{role}} = 0.5 \cdot \text{median}(n_{\text{pres, role}})$ ensures proven high-volume performers outrank low-volume outliers, while secondary skills only add value above cohort average.

4. Two-Stage Match-Cluster Bootstrap

Resamples 300 match-level iterations (plus intra-match ball resampling when active matches $\le 2$) to quantify realistic 95% confidence bounds:

$$\text{CI}_{95\%} = \big[Q_{0.025}(\hat{\theta}^*_b),\; Q_{0.975}(\hat{\theta}^*_b)\big]_{b=1}^{300}$$

Prevents intraday correlation distortion and exposes wide intervals on lower-volume performers so sample sensitivity remains transparent.
